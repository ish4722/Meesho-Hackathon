# Evaluation report (synthetic data)

> **Everything below is measured on synthetic data generated by `synth_market.py`.** The numbers show how well the pipeline recovers assumptions that were built into the generator. They are not evidence of accuracy on real Meesho listings, and good synthetic scores must not be quoted as real-world performance.

Design: models trained on the 60% training listings using weeks before **2026-03-02**; validation and final holdout listings never enter training. Split counts: {'train': 360, 'holdout': 120, 'validation': 120}. No setting was tuned on validation or holdout results. Quick mode: False.
